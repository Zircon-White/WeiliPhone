# 小手机 · PhoneShell

> **一个跑在浏览器里的单文件手机模拟器。**
> 双击 `phone.html` 就是一台手机：桌面、应用商店、AI 现场创作、阅读器、睡前故事、拼图……全部塞进一个 HTML 文件里。
> 所有美术（图标、壁纸、示例图、游戏画面）都由代码实时绘制，**零外部图片、零字体、零 CDN、零安装**。

> **版本**：v1.7.0　·　**交付物**：`phone.html`（单文件，约 670 KB）　·　**依赖**：无　·　**目标浏览器**：Chrome / Edge　·　**测试**：545 + 75 项全绿

> 项目本身不加载任何外部资源；把 `phone.html` 拷到 U 盘、断网也能完整运行。

---

## ✨ 它能做什么

- 📦 **单文件交付**：`build.mjs` 把 `src/` 内联成 `phone.html`（约 670 KB），双击即用，不需要 Node、不需要安装。
- 🧩 **13 个内置应用 / 游戏**：2048、五子棋、UNO、贪吃蛇、**拼图**、时钟、便签、阅读器、睡前故事、计算器、应用商店、AI 创作、设置。
- 🛠️ **插件系统**：一个应用就是一段 `createApp(phone)` 的 JS 源码，可安装、卸载、导入、导出；「AI 创作」能让你的对话模型**现场写一个新应用并装到桌面**。
- 🖥️ **桌面体验**：3 页桌面、长按整理、拖拽排序、文件夹、纯色 / 渐变壁纸、锁屏、闲置息屏 + 知识卡。
- 🔌 **统一 API 管理**：对话 / 长文创作 / 联网检索 / 语音合成四类接口，密钥只存本机；兼容 OpenAI 协议与本地 **GPT-SoVITS**。
- 📖 **阅读器**：导入 txt / md / csv / json / html，段落分页、记忆进度、关键词检索、AI 总结、划线询问、日间 / 夜间配色。
- 🌙 **睡前故事**：自己写最终提示词 → 长文模型写稿 → 自动切段 → 本地 GPT-SoVITS 边生成边朗读，支持收藏与导出。
- 🧩 **拼图**：导入自己的照片，6~1000 片，经典 / 异形两种切法；**可缩放平移、自动保存进度、绿色吸附提示可关**。
- 💾 **本地优先**：便签、阅读进度、睡前故事、拼图存档、接口配置都存在本机浏览器（localStorage / IndexedDB），关掉再开接着用。
- 🎨 **全部由代码画**：图标是内联 SVG / emoji，壁纸、示例图、游戏画面用 CSS / Canvas 现场绘制，不引用任何外部图片或字体。

## 🚀 快速开始

### 方式一：直接用（推荐）

1. 下载本仓库，或者只下载 [phone.html](phone.html)。
2. **双击 `phone.html`**，或者在 Windows 上双击 `启动小手机.bat` / `启动小手机-独立窗口.bat`。
3. 首次打开是锁屏，点一下 / 上滑就能进桌面。

> 启动脚本是 Windows 专用的；macOS / Linux 直接双击 `phone.html` 用浏览器打开即可。

### 方式二：从源码构建（可选）

需要 **Node 18+**：

```bash
node build.mjs              # 把 src/ 打包成 phone.html
node tests/smoke.mjs        # 内核回归（当前 545 项，必须 0 失败）
node tests/verify-html.mjs  # 产物验收（当前 75 项，必须 0 失败）
```

`phone.html` 是构建产物，运行它**不需要 Node**；只有改源码时才需要重新构建。

## 🛠️ 写一个自己的应用

应用就是一段约定格式的 JS，保存在 `src/apps/你的应用.js`，重新构建即可：

```js
function createApp(phone) {
  return {
    id: 'guess',                 // 字母开头，2~32 位
    name: '猜数字',
    icon: 'emoji:🎯',            // 或 'svg:内置图标名'
    desc: '1~100 猜数字',
    mount: function (phone, root, ctx) {
      root.appendChild(phone.utils.el('div', 'ui-card', 'Hello PhoneShell!'));
    }
  };
}
```

- 也可以在「应用商店 → 粘贴源码安装」，或让「AI 创作」现场生成；
- 完整的 `ctx` 方法、`phone.*` API、UI 样式类见 **[MANUAL.md](MANUAL.md) 第九节**。

## 📂 目录结构

```
phone.html               # 构建产物：双击即用的单文件手机（提交到仓库）
build.mjs                # 构建脚本：把 src/ 内联成单文件（含产物自检）
src/
  shell.html             # HTML 模板（含占位标记与息屏屏保结构）
  core.css               # 全部样式
  core.js                # 内核：桌面 / 注册表 / 存储 / API / 息屏 / 弹窗
  apps/*.js              # 内置应用（一个文件一个应用）
  games/*.js             # 内置游戏
tests/
  smoke.mjs              # 内核冒烟（假 DOM 真跑 core.js + 全部应用）
  verify-html.mjs        # 产物验收（结构 / 语法 / 假 DOM 真跑产物）
启动小手机.bat            # Windows：默认浏览器打开（可选同步启动 GPT-SoVITS）
启动小手机-独立窗口.bat     # Windows：用 Edge/Chrome --app 模式打开成手机窗口
同步启动GPT-SoVITS.bat     # 「没在跑就拉起来」的启动逻辑
MANUAL.md                # 完整使用手册
HANDOFF.md               # 开发交接：架构、契约、踩过的坑、测试脚手架
.gitignore               # 排除本机私有文件（清单见 HANDOFF 第 11 节）
```

## 🔒 数据与隐私

- 所有数据（便签、阅读进度、睡前故事、音色库、拼图存档、接口配置）默认只存在**本机浏览器**的 localStorage / IndexedDB；**只有你主动使用 AI 创作 / 总结 / 知识卡 / 语音时，相关文本才会发给你自己在「API 管理」里配置的接口**——本项目没有自己的服务器。
- 接口 Key 也只保存在本机；**本仓库不包含任何真实的 API Key**（测试里的 `sk-test` 是假数据）。
- 打开 `phone.html` 不需要联网；需要联网的功能（AI 创作、知识卡、语音）取决于你自己在「设置 → API 管理」里配置的接口。
- 仓库中**不应**提交：`gptsovits-launch.ini`（本机 GPT-SoVITS 路径）、`*.lnk`（本机快捷方式）、`tmp/`（调试脚本）、`phoneshell-backup-*.json`（备份里含接口配置与全部应用数据）。根目录的 `.gitignore` 已覆盖这些。
- 具体清单与上传前自检命令见 **[HANDOFF.md](HANDOFF.md) 第 11 节「上传到 GitHub / 隐私清单」**。

## ⚠️ 已知限制

- 目标浏览器是 **Chrome / Edge**（用到 `backdrop-filter`、`-webkit-line-clamp` 等现代特性），不支持 IE。
- 本地 `file://` 打开时，部分接口可能被浏览器 CORS 拦截；需要时可改用本地 http 服务（例如 `python -m http.server`）。
- 本地 GPT-SoVITS 默认没开跨域，语音接口默认用「自动 / 直连播放」策略。
- 没有做真实浏览器自动化测试（开发环境限制），目前靠两套 Node 测试 + 人工验收。
